## 🚀 How to Run locally
* For standard static HTML/JS projects (**Experiment 1-7, 9**): Open the respective `index.html` file in any modern web browser.
* For server-side PHP/MySQL projects (**Experiment 8, 10**):
  1. Ensure you have XAMPP/WAMP installed.
  2. Put the `webtech_bishal` folder inside `htdocs` (or `www`).
  3. Start the Apache and MySQL modules.
  4. Follow internal instructions to import `database.sql` dependencies for DB functionality.
  5. Navigate to `http://localhost/webtech_bishal` in your browser.
